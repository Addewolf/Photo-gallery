# Different Pictures — private gallery prototype

A static, responsive HTML/CSS/JavaScript photography gallery using photographs shared in the conversation.

## Preview locally
Open `index.html` in a browser. No build tools, account, or server required.

## Privacy
**Not published.** Do not enable GitHub Pages until ready for a public website. A private GitHub repository does **not** automatically make a GitHub Pages site private.

## GitHub setup
Create a **private** repository on GitHub, then upload these files or initialize a local repository and push it. Keep Pages disabled.

## Notes
Photograph titles and categories are provisional. Images are compressed for website use. The original uploads have not been changed. To add photographs, add a compressed image to `images/` and a matching entry in the `photos` array in `script.js`.
